# 起動と使い方（配布手順書）

DBビューア（Web 版）を現場の PC に置いて使うまでの手順と、画面ごとの使い方です。
VBA 版（汎用システム / 作業標準管理システム）を使っていた人が、同じ操作を Web 版で
探せるように、対応する VBA の画面・ボタン名を併記しています。

## 1. 配布先 PC に必要なもの

| 項目 | 内容 |
|---|---|
| Windows | 日本語 Windows 10 / 11（`Start.vbs` `start.bat` は CP932 前提） |
| Python | 3.11 以上。インストール時に「Add python.exe to PATH」にチェック |
| 追加パッケージ | **Flask と waitress の 2 つだけ**（`requirements.txt`）。それ以外は標準ライブラリ |
| Access Database Engine（ACE） | **Access(.accdb) から取り込むときだけ**必要。一覧・登録・帳票の通常運用には不要 |
| ブラウザ | Edge または Chrome（画面はブラウザで開く） |

追加パッケージの入れ方（どちらか）:

```
pip install -r requirements.txt
```

pip が外に出られない PC には、Flask / waitress とその依存の wheel をフォルダごと配って:

```
pip install --no-index --find-links=wheels -r requirements.txt
```

## 2. 置き場所と起動

> 0.6.0 から**デスクトップ版**(`DBビューア.exe`、専用の窓。ポートを使わない)があります。配布フォルダで
> `scripts\make_shortcuts.vbs` を押すと `DBビューア(デスクトップ版).lnk` と `DBビューア(ブラウザ版).lnk` ができます。
> 2つは同時に動きません(後から開いたほうが理由を出して止まる)。作りと配り方は [08_デスクトップ版.md](08_デスクトップ版.md)。
> 下はブラウザ版(予備)の起動です。デスクトップ版でも、ログイン以降の使い方は同じです。

1. リポジトリ一式（`Start.vbs` `start_app.py` `app/` `dbviewer/` `config/` `vendor/` …）を任意のフォルダに置く。共有フォルダ上でも動く。
2. **`Start.vbs` をダブルクリック**。コンソールを出さずに起動し、ブラウザが自動で開く。
   - 起動しないときは `start.bat`。コンソールに理由が出る（Python 無し、パッケージ無し、ポート使用中など）。
   - `start.bat --check` は環境確認だけして終わる。
3. 初回だけ「**起動モードの設定**」が出る（VBA の regUF と同じ）。オンライン（共有フォルダの本体）かオフライン（手元のフォルダ）を選んで「設定」。
4. ログイン画面で ID とパスワード。ID にはこの PC の OS ログイン ID が入っている（VBA の Login と同じ。`ID` テーブルの ID と PC の両方が一致する行で確かめる）。
5. 終わるときは画面右上の「終了」。全部のタブを閉じても、しばらくして自動で終わる。`stop.bat` は強制停止。

ポートは `config/app.json` の 8743。既に同じアプリが動いていれば、そのブラウザ画面を開き直す（多重起動しない）。

## 3. 本体（DB）の準備

Web 版の本体は **SQLite（`作業標準管理システム.sqlite3`）** です。Access の `.accdb` を直接は読みません。

### 3-1. 初回: Access(.accdb)を .sqlite3 に変換して保存

目的は**脱 .accdb**。一度 .sqlite3 にしたら、あとは .sqlite3 だけを使う。

設定 → 「Access 取り込み」タブ(「接続先」のファイル一覧で .accdb の「Access 取り込みへ」を押すと、元と保存先が入った状態で開く):

1. 「元の .accdb」に `作業標準管理システム.accdb` を入れる（「参照…」でサーバ側のフォルダを辿れる）。
2. 「保存先(.sqlite3)」を入れる。空なら、いまの接続先フォルダに Access と同じ名前で作る。フォルダだけ選んでもよい(名前は Access と同じ)。
3. 「変換して保存」。`cscript.exe → bridge.vbs → ADODB.Connection → ACE OLE DB` の経路で全テーブルを読み、`.sqlite3` に書く。進み具合は帯に出る。保存先に同じ名前があれば `.bak` に退けてから差し替える。
4. 終わったら「この .sqlite3 を開く」で接続先にする。

Linux の CI・開発機（cscript が無い）では `tests/fixtures/realdata/` の TSV から同じ取り込み処理でテスト用 DB を作っている。

### 3-2. 上級: 表だけ持ってくる（丸ごと差し替えない）

Access で表を作った・列を足したときは、設定 → Access 取り込み →「**表を持ってくる…**」を使う
（python-web-tools と同じ画面）。丸ごと差し替え（3-1）と違い、Web 版で登録した行は消えない。

1. Access（.accdb）か、変換した .sqlite3 をダイアログへドラッグ&ドロップ（または「参照…」で選んで「中を見る」）。
   読むのはいつも .sqlite3 で、Access のときは 3-1 と同じ経路で作業フォルダに .sqlite3 を作ってから読む。
2. 表ごとに出る:
   - **本体に無い表** … チェックして「選んだ表を持ってくる」。表・中身・索引を足す
   - **もうある表** …「入れ替える」（Access で列を足しただけ）か「作り直す」（列を消した・名前を変えた。
     今の表は `表名_作り直す前_日時` で残す）を選んで「選んだ表を入れ替える・作り直す」
   - **もうある（入れ替えられない）** … メインテーブル・H_ 履歴（Web 版が書く表）と ID
3. 書く前に本体の控えを `%LOCALAPPDATA%\DBViewer\backup` に取る。何をしたかは
   `logs\取り込み診断_YYYYMMDD.log` に残る。
4. 書けるのは **Level 5 でログインしているとき**だけ。足した表はマスタ管理に「足」の印で出る。

### 3-3. 接続先

「接続先」タブの下に、**接続先フォルダの中のファイル**が出る(フォルダの欄を変えるとすぐ見直す)。

| 表示 | 意味 | 押せるもの |
|---|---|---|
| 緑の枠「開けます」 | 業務の表がある .sqlite3。DBビューアの形(全般設定・ID・メインテーブル)なら件数、そうでなければ「表は自動・閲覧だけ」と出る(0.7.0) | 「これを開く」で接続先にする |
| 青い枠「いま開いている」 | いまの本体 | — |
| 橙の枠「変換すると開けます」 | Access(.accdb / .mdb)。同じ名前の .sqlite3 があれば「変換済み」と出る | 「Access 取り込みへ」 |
| 薄く「対象外」 | 表が 1 つも無い・読めない | — |

設定 → 「接続先」タブ。VBA の `progNo`・レジストリ「起動設定/モード」・`SrvPath` にあたる。

| 項目 | VBA | Web 版 |
|---|---|---|
| システム | `progNo`（1〜7） | 「システム」の選択。本体ファイル名と共有フォルダの既定が決まる |
| オンライン/オフライン | レジストリ `SysName\起動設定\モード` | チェックボックス。空にしたいときはログイン画面の「起動モードを初期化」 |
| 共有フォルダ | `プログラム番号チェック` の固定パス | 「共有フォルダ(オンライン)」。空なら VBA と同じ既定 |
| 手元のフォルダ | ブックと同じフォルダ | 「手元のフォルダ(オフライン)」。空ならアプリのフォルダ |
| 本体ファイル | `xxx.accdb` | `xxx.sqlite3`。空ならシステムの既定名 |

保存すると「いまの状態」タブに、到達できたか・設定の表がそろっているか・表示する表と列の決まり(足りないところの案内)が出る。

### 3-4. かんたん設定(0.8.0 / 0.9.0)

決めるのは **見る DB**(上の「接続先」)と、表ごとの **列の設定** だけ。全般設定・`_設定`・管理番号 は要らない。
詳しくは [09](09_かんたん設定.md)。

1. 設定 →「かんたん設定」で表を選ぶ
2. 列ごとに **表示**(一覧・閲覧に出す)・**入力**(文字 / コンボボックス / スピンボタン(刻み)/ カレンダー)・**印刷**(閲覧・出力の印刷と保存に入れる)を選んで保存(Level 5)
3. 一覧の上で表を選ぶと、その表をその場で直せる(マスタ管理・閲覧でも同じ表が見られる)

設定は DB の中に**列名で**覚える。DB を替えればその DB の設定、列が増えれば既定(表示・文字・印刷)で出る。
ID の表が無い DB は誰でも直せる。人を決めたいときだけ「ログイン」で自分を Level 5 で登録する。
作業標準管理_設定 などの VBA 版の設定の表は使わない(0.9.0)。かんたん設定の「取り込んで消す」で入力の種類を取り込んでから消せる。

## 4. 画面の使い方（VBA との対応）

左のレールが VBA のボタンにあたる。

| Web 版 | VBA | できること |
|---|---|---|
| 1 一覧 | MF1 ページ 1 | フィルタで絞る、見出しダブルクリックで集計、行を選んで 新規/修正/削除/参照、帳票、出力 |
| 一覧 → 新規/修正/削除/参照 | MF1 ページ 2 | 入力形式に応じた補助入力（マスタ選択、カレンダー、数値、フォルダ、フィールド）、必須、履歴、確認メッセージ |
| 2 マスタ管理 | MF2（SETTING ボタン） | Level に応じた設定表・マスタ表の新規/修正/削除 |
| 3 閲覧・出力 | MF3（BROWSE）、OUTPUT | 全般設定「テーブル閲覧」の表を見る、xlsx / txt / csv に出す、印刷用 HTML |
| 4 設定 | regUF・レジストリ・進入不可の固定値 | 接続先、参照・出力(保存先・形式・参照ファイルの起点)、動作、Access 取り込み、この端末 |

### 4-1. 一覧

VBA の一覧(フィルタ列 + ListView + ページ)は使わず、全件を 1 枚の表で見る。

| したいこと | やり方 |
|---|---|
| 並べ替える | 見出しの名前を押す(昇順 → 降順 → 元に戻す)。Shift を押しながら押すと 2 段目・3 段目の並べ替えを足せる |
| 列で絞り込む | 見出しの ▾。値の一覧(件数つき)のチェックで選ぶ。「値を探す」で一覧を絞れる(Enter で探した値だけにする)。数値・日付の列は範囲でも絞れる |
| どの列にあっても探す | 上の検索欄。スペースで区切ると全部を含む行。全角/半角(ﾊﾝﾏｰ と ハンマー)、大文字/小文字を区別しない |
| 条件を外す | 表の上の札の ×、または「絞り込みを解除」 |
| 列の表示・並び・幅 | 「列の設定」でチェックを外すと隠れる、▲▼ かドラッグで並べ替え。見出しをドラッグしても並びが変わる。幅は見出しの右端をドラッグ(ダブルクリックで自動)。**この PC に保存され、次に開いても同じ**。「初期の並びに戻す」で元に戻る |
| 行の中身を全部見る | 行を押すと右の「詳細」に全部の列(隠した列も)。「詳細」ボタンで出す/隠す |
| その場で直す | **マスをダブルクリック** → 打って Enter(または他を押す)で**すぐ .sqlite3 に保存**。確認は出ない。Esc で取り消し。数値・日付・マスタの欄は登録画面と同じ選ぶ窓が出る。保存したマスは一瞬緑になり、上に「保存しました」 |
| 修正・参照・削除 | 行を選んで上のボタン(登録画面で全部の欄を直す)。Enter も修正。直せない列(管理番号・自動項目)のダブルクリックは理由を出す。Level 1 はダブルクリックで参照。↑↓ で行を移れる |

- 絞り込み・並べ替え・選んだ行は、レコード画面から戻っても残る(タブごと)。レコード画面の ▲▼ は一覧に並んでいる順に進む。
- 集計(VBA の見出しダブルクリック)は、▾ の値の一覧に件数が出るので、そこで見る。
- **帳票**: 全般設定「帳票」があるときだけ出る。いま絞り込んでいる行で作り、並びは帳票の決まり(VBA と同じ)。Excel の原紙は使わず、印刷用の画面(A4・余白 6mm)で出る。
- **印刷**: いま見えている表(行・列・並び)をそのまま A4 横で。列が多ければ紙の幅に縮める。開いた画面で Ctrl+P(プリンタに「PDF に保存」を選べば PDF)。
- **出力 ▾**: 「表をコピー」で Excel・メールにそのまま貼れる(ファイルを作らない)。「ファイルに保存…」は設定「出力先」のフォルダに CSV など(4-4)。
- 他の端末が本体を書き換えると、上に「他の端末で更新されました」帯が出る。「再読込」で読み直す(絞り込みは残る)。

### 4-2. 登録画面

- 入力形式ごとの色と補助入力は VBA と同じ規則（`_設定` テーブルの「入力形式」）。
- 必須未入力は赤くして止まる。修正で変更が無ければ「修正箇所がないため、キャンセルします」。
- 確認メッセージ（「新規登録しますか？」「既に登録されているデータがあります。上書きしますか？」など）は VBA と同じ文言。
- 画面を開いたあとに別の端末が同じ行を書き換えていた場合は「他の端末が先に変更しました」と止まる（VBA は後勝ちで黙って上書きしていた。意図した差異）。

### 4-3. マスタ管理

- 表の列名を押すと並べ替え(昇順 → 降順 → 元の並び)。数値・日付は値の順、空欄はいつも下。並べ替えは表ごとに覚え、直して戻っても同じ並び。補助入力でマスタから選ぶ窓(「…」)も同じく列名で並べ替えられる。

- 出すのは**いま使っている表だけ**(表の名前の下に理由が出る)。作業標準管理システムでは次の 3 つ:
  - `ID` … ログイン(Level 4 以上)
  - `全般設定` … メインテーブル名・帳票・テーブル閲覧・初期フィルタ
  - `作業標準管理_設定` … 登録画面と一覧で直すときの決まり(入力形式・必須・履歴…)
  - ほかに、`_設定` が参照するマスタ(入力形式 s/m・マスタ結合)、`_設定` の「履歴」の H_ 表(見るだけ)、「表を持ってくる」で足した表があれば出る
- `フィルタ`・`フィルタ_設定`・`タイプ` は一覧が使わなくなったので出さない(本体に残っていても害はない。無くても起動する)。
- Level 3 以上で使える。Level 2 以下で直せる表はない。
- 削除は VBA と同じく「全列一致」で対象を引き直す。

#### 行を追加・列を追加

脱 .accdb で本体が .sqlite3 になり、Access を開いて表を直すことができなくなったので、マスタ管理で足せるようにした。

| ボタン | すること | 使える人 |
|---|---|---|
| **＋ 行を追加** | 今までの「新規」。1 列目は自動の番号。足した行は選ばれて見えるところに出る | その表を直せる Level(上の決まり) |
| **＋ 列を追加** | 選んだ表の**いちばん右**に列を足す。列名・種類(文字 / 整数 / 数値)・いまある行に入れる値(空でよい)を決める | **Level 5**(表の形を変えるため。足す前に本体の控えを `backup` に取る) |

- **本体(`作業標準管理`)に列を足す**: Level 5 だと左の一覧に本体も出る(行はここでは直さない。一覧で)。
  列を足すと `作業標準管理_設定` にも同じ名前の行が**同時に**できる(本体の列と `_設定` の行は 1 対 1 で、合わないと起動が止まるため)。
  足した行の入力形式などは空(= 自由入力)。知らせの「設定の行を直す」を押すとその行が開くので、入力形式・必須・表示などを決める。
  すぐ一覧に列が出て、その場で直せる。
- **`作業標準管理_設定` に行を足す**のも同じこと(本体にその項目名の列ができる)。入力形式などを先に入れてから足せる。Level 5。
- `作業標準管理_設定` の **項目名の変更と行の削除はできない**(本体の列と合わなくなり、起動できなくなるため。VBA では消せて、壊れていた)。
- 列名に `[` `]` `"` `` ` `` と改行は使えない。もうある列名(大文字・小文字の違いも同じとみなす)、一覧に出しているマスタ結合・追加表示の名前とも重ねられない。
- 列が決まっている表(`全般設定`・`_設定`・H_ 履歴)には列を足せない。

### 4-4. 閲覧・出力

- 閲覧は業務の表ぜんぶ(全般設定「テーブル閲覧」の表も)を、一覧と同じ表(並べ替え・絞り込み・列の設定)で見る。印刷・コピー・保存に入る列は かんたん設定 の「印刷」の列。
- Level 5 なら「＋ 列を追加」で見ている表に列を足せる(一覧の「新規」の右にも同じボタン)。
- **ダウンロードはしない。** 保存は設定 →「参照・出力」の「保存先フォルダ」に書き、場所を出す(Windows では「フォルダを開く」で開ける)。空ならこの PC のローカル領域(`%LOCALAPPDATA%\DBViewer\work\出力`)。同じ名前があれば `_2` を付ける(上書きしない)。
- 形式は CSV(既定)・タブ区切り(.txt)・Excel 形式(.xlsx)。CSV/タブ区切りはふつうの形(値にカンマや改行があれば "…" で囲む)。文字コードは Shift_JIS(日本語版 Excel でそのまま開ける)か UTF-8。
- xlsx は標準ライブラリだけで書く同梱の writer(`vendor/xlsx_writer.py`)。Excel が無い PC でも作れる。

## 5. 記録と設定の場所

| 内容 | 場所 |
|---|---|
| この端末の設定（VBA のレジストリ） | `%LOCALAPPDATA%\DBViewer\data\user_config.json` |
| 操作の記録(なぜなぜ分析用) | 既定 `%LOCALAPPDATA%\DBViewer\logs\記録_<PC名>_YYYYMMDD.jsonl`。**設定「記録」で置き場所(共有フォルダ可)と残す日数を変えられる**。読み方は [07_ログとなぜなぜ分析.md](07_ログとなぜなぜ分析.md) |
| アプリのログ(開発者向け) | 記録と同じフォルダの `dbviewer_<PC名>_YYYYMMDD.log`（日替わり） |
| Access.log（VBA と同じ TSV） | 本体と同じフォルダ。設定「動作」で止められる。書く内容は VBA と同じ「認証成功」「認証失敗」の 2 種 |

## 6. 困ったとき

| 症状 | 見るところ |
|---|---|
| エラーが出た・保存できなかった | 知らせに出た **記録番号** を 設定 →「記録」→「記録番号で引く」に入れる(知らせの「記録を見る」でも同じ)。前後の操作と、なぜなぜの下書きが出る |
| ダブルクリックしても何も起きない | `start.bat` で起動して理由を読む。記録の置き場所(既定 `%LOCALAPPDATA%\DBViewer\logs`)の最新の `dbviewer_*.log` |
| 「対象ファイルに接続できません」 | 設定 → 接続先。本体ファイルの場所と名前。同じフォルダにある `.sqlite3` の候補名が出る |
| 「起動を中止します」の整合性エラー | 設定 → いまの状態。`_設定` の行順とメインの列順、フィルタ列の存在（VBA と同じ判定） |
| Access から取り込めない | この PC に ACE（Access Database Engine）があるか。`cscript` の出力はログに残る |
| 他の端末の変更が見えない | 一覧の「再読込」。心拍（15 秒ごと）で本体の更新時刻を見ている |
| 画面が「接続が切れました」 | プロセスが終わっている。`Start.vbs` で起動し直す |

## 7. 開発者向け
