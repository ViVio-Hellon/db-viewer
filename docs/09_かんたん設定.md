# かんたん設定(0.8.0 / 0.9.0)

VBA 版は、使い始めるまでに決まった表(全般設定・ID・`<メイン>_設定`)をそろえ、決まった書き方
(`calender@過去`・`s担当者`・`数値1/0/100/5` …)で打つ必要があり、**設定が面倒すぎて誰も設定できません**でした。

0.8.0 からは、決めるのは次の 2 つだけです。

| 決めること | どこで | 中身 |
|---|---|---|
| **見る DB** | 設定 →「接続先」 | どの .sqlite3 を見るか |
| **列の設定**(表ごと) | 設定 →「かんたん設定」 | 列ごとに **表示**・**入力**・**印刷** |

全般設定・`<表>_設定`・管理番号 は**要りません**。どの表も、一覧・マスタ管理・閲覧で見て直せます。

## 1. どの表も見て直せる

| 画面 | できること |
|---|---|
| 一覧 | 上の欄で**表を選ぶ**(この PC で覚える)。マスをダブルクリックしてその場で直す(すぐ保存)。新規・修正・参照は行の窓、削除は確かめてから |
| マスタ管理 | 左に**業務の表がぜんぶ**並ぶ。表示しない列も含めて全部の列を、入力の種類どおりの欄で直す |
| 閲覧・出力 | 業務の表がぜんぶ並ぶ。印刷・保存・コピーには「印刷」の列だけが入る |

- 行は SQLite の **rowid**(どの表にもある行の番号)で決めます。管理番号の列は要りません。
- 直すときは「画面が見ていた値」といまの値を比べ、ほかの端末が先に変えていたら書きません(「もう一度」と出る)。
- 数の型の列(INTEGER・REAL)に数を打てば、数として書きます(文字の "1500" にしない。カンマも外す)。
- 業務の表 = システムが読む表(ID・全般設定・フィルタ・タイプ・`*_設定`・`H_*`・ツールの設定)以外。

## 2. 列の設定(設定 → かんたん設定)

```
┌ 見る DB ──────────────────────────────┐
│ \\server\共有\部品台帳.sqlite3          │  替えるときは「接続先」
└───────────────────────────────────────┘
┌ 列の設定 ─────────────── [部品] の 5 列 ┐
│ 表 [部品(3 件) ▾]                        │
│ 列     表示  入力                    印刷 │
│ 品番    ☑   [文字 ▾]                  □  │
│ 名前    ☑   [コンボボックス ▾]        ☑  │
│ 単価    ☑   [スピンボタン ▾] 刻み 0.5 ☑  │
│ 入荷日  ☑   [カレンダー ▾]            ☑  │
│ [列の設定を保存]                          │  Level 5
└───────────────────────────────────────┘
┌ ログイン ─────────────── 使わなくてもよい ┐
│ ID の表が無いので、誰でも見て直せます。   │
│ 名前 [  ] パスワード [  ] [自分を Level 5 で登録してログインを使う] │
└───────────────────────────────────────┘
```

| 設定 | 意味 |
|---|---|
| **表示** | 一覧・閲覧に出すか(マスタ管理はいつも全部の列) |
| **入力: 文字** | ふつうの欄 |
| **入力: コンボボックス** | その列に**入っている値**から選ぶ(打ってもよい)。選択肢を別に用意しなくてよい |
| **入力: スピンボタン** | 数の欄(▲▼)。**刻み** を決められる。数でなければ断る |
| **入力: カレンダー** | 日付の欄(カレンダーから選ぶ)。書く形はその列の今の形(`2026/10/15`。`2026-10-15` の列ならそれ)。無い日付は断る |
| **入力: 自動: 登録した人** | 行を足したときに、ログインした人の ID が入る(画面では直せない)。0.10.0 |
| **入力: 自動: 直した人** | 行を足した・直したときに、ログインした人の ID が入る(何も変わっていなければ入れない)。0.10.0 |
| **入力: ファイル** | ファイルの場所(`図面\A-1.pdf` のような相対パスは 設定「参照ファイルの起点」から、絶対パスも可)。マスのダブルクリック・詳細・行の窓の「プレビュー」で、**アプリの窓の中で見る**(ほかのアプリでは開かない・ダウンロードもしない)。見られるのは PDF・画像(png・jpg・gif・bmp・webp)・テキスト(txt・csv・log。Shift_JIS も可)。0.10.0 |
| **印刷** | 閲覧・出力で 印刷・保存・コピー に入れるか |

### 汎用に使えるか(DB を替えたら列はどうなるか)

- 設定は **DB の中の隠した表「ツールの設定」** に、**表ごと・列名ごと** に覚えます。DB を使う全員で同じです。
- **列名で**覚えるので、列の並びが変わっても**ずれません**。列が増えれば、その列は既定(表示・文字・印刷)で出ます。
- **DB を替えれば、その DB の設定**になります(その DB に設定が無ければ、どの列も既定)。前の DB の設定が別の DB に勝手に移ることはありません。
- 列の一覧は、いつも**いま開いている表の本当の列**から作ります。設定の側で列を数え直す必要はありません。

## 3. ログイン(使わなくてもよい)

- **ID の表が無い DB は、誰でも見て直せます**(Level 5)。ファイルを開ける人はもともと直せるためです。
- 人とレベルを決めたいときだけ、かんたん設定の「ログイン」で自分を Level 5 で登録します(ID の表を作る)。
  次からはログインが要り、人を足すのは マスタ管理 の ID で(Level 4 以上)。
- ID の表がある DB(VBA 版の DB)は今までどおり、ID・PC・パスワード・Level で決まります。

## 4. VBA 版の DB(作業標準管理 など)も同じ(0.9.0)

`<表>_設定`(作業標準管理_設定 など)は**画面では使いません**。作業標準管理も、ほかの表と同じく
かんたん設定の 表示・入力・印刷 で動きます(一覧で直す・行の窓・マスタ管理で直す)。

- かんたん設定をまだ保存していない表は、`<表>_設定` の入力形式から**最初の設定**を作ります:

  | VBA 版の入力形式 | かんたん設定 |
  |---|---|
  | `calender`(`@過去`・`@未来` も) | カレンダー |
  | `数値N/最小/最大/刻み` | スピンボタン(刻みもそのまま) |
  | `s<表>` / `m<表>` | コンボボックス |
  | `#NEWUSER#` / `#UPUSER#` | 自動: 登録した人 / 自動: 直した人(0.10.0) |
  | ほか(日時の自動・`#VIEW#`・`$フォーム`・`数値変換`) | 文字 |

  作業標準管理_設定 では Ⅰ〜Ⅳ = スピンボタン、登録日・更新日・完了日 = カレンダー、登録者・更新者 = 自動: 直した人
  (VBA 版の `#UPUSER#` のまま。登録者を「足したときだけ」にするなら かんたん設定で 自動: 登録した人 に)、ほかは文字になります。
  すでに「取り込んで消す」をした DB は、かんたん設定で 登録者・更新者 の入力を選び直してください。
- 設定 → かんたん設定 の「**VBA 版の設定の表**」→「**取り込んで消す**」(Level 5)で、上の設定を「ツールの設定」に
  保存してから、`*_設定` の表をぜんぶ消します(消す前に本体の控えを取る)。
- 帳票(全般設定「帳票」)は今までどおり作れます(全般設定の「メインテーブル名」の表を一覧で見ているとき)。
  全般設定 はこの帳票のためだけに残っています(無ければ帳票のボタンが出ないだけ)。

**やめたもの**(VBA 版の `_設定` でしかできなかったこと): 日時の自動入力、必須、マスタ結合・追加表示、
金額の "#,##0" 表示、文字色、変更履歴(H_ 表への書き込み)、登録画面。
(登録者・更新者の自動入力と、参照ファイルのプレビューは 0.10.0 で かんたん設定 に足した)
H_ 表は消えず、マスタ管理で見られます。

## 5. 列を追加

一覧(「新規」の右)・閲覧・出力・マスタ管理の「＋ 列を追加」(Level 5)。列名・種類(文字・整数・数値)・いまある行に入れる値を決めて、いちばん右に足します。足す前に本体の控えを取ります。足した列は かんたん設定 で 表示・入力・印刷 を決めます。

## 6. 試験

`tests/test_easy_setup.py`: (0.9.0)VBA 版の DB も同じ道・_設定 から最初の設定・取り込んで消す・帳票は rowid でも作れる。設定の表が 1 つも無い DB を開く(誰でも Level 5)→ 一覧で表を選ぶ・マスを直す(rowid・
ほかの端末が先に変えていたら断る)→ 行の窓で足す・消す → 列の設定(コンボの選択肢・スピンの数の確かめ・カレンダーの形)
→ 表示しない列は一覧・閲覧に出ない・印刷しない列は閲覧の印刷に入らない → マスタ管理で入力の種類どおり → 列名で覚える
(列を足しても・並びが違う DB でもずれない)→ ログインを使う → VBA 版の DB は今までどおり、など。
画面は Chromium で、表の選択・カレンダーのマス・新規の窓・閲覧の印刷列・マスタ管理の欄まで通して確かめた(JS のエラー無し)。
