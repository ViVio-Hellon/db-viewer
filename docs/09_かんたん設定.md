# かんたん設定(0.7.0)

VBA 版は、使い始めるまでに**決まった 4 つの表**をそろえ、決まった書き方で文字を打つ必要がありました。

| VBA 版で要ったもの | 難しかったところ |
|---|---|
| 全般設定 | 「メインテーブル名」などを表に打つ |
| ID | 誰が・どの PC で・どのレベルかを表に打つ |
| `<メイン>_設定` | 本体の列と**同じ数・同じ並び**の行。1 つでも違うと「起動を中止します」 |
| 入力形式の書き方 | `calender@過去`・`s担当者`・`数値1/0/100/5`・`#NEWUSER#` … を覚える |

0.7.0 から、**どの DB でもまず開いて見られる**ようにし、編集に要る決まりは**画面で選ぶ**ようにしました。
今までの DB(4 つの表がそろったもの)はそのまま動きます。

## 1. 設定が無い・合わないときの動き(止めずに補う)

| 場面 | 0.6.0 まで | 0.7.0 から |
|---|---|---|
| 全般設定が無い・「メインテーブル名」が空・その表が無い | 起動しない | 業務の表の 1 つ目を出す(この PC で選び直せる)。案内を出す |
| `<メイン>_設定` が無い | 起動しない | どの列も**自由入力**で動く。案内を出す |
| `<メイン>_設定` と本体の**数・並び**が違う | 「起動を中止します」 | **項目名で合わせる**。足りない列は自由入力、本体に無い項目は使わない。案内を出す |
| ID が無い | 起動しない | **閲覧だけ**でログインできる(Level 1)。「編集を始める」で自分を登録 |
| 本体に「管理番号」が無い | 起動しない | 見られる。一覧で行を直す・足す・消すのボタンは出さない(かんたん設定で足せる) |
| 設定 → 接続先 の DB の一覧 | 全般設定・ID が無い .sqlite3 は「DBビューアの形ではありません」 | 業務の表があれば「開ける」(表は自動・閲覧だけ と添える) |
| 閲覧・出力 | 全般設定「テーブル閲覧」が空なら何も見られない | 空なら**業務の表ぜんぶ**(ID は出さない) |
| マスタ管理 | 使っている表だけ | 設定の無い DB では業務の表ぜんぶ(どの表の行も足せる)。設定のある DB は今までどおり |
| CheckColumns(マスタの 2 列目 = 表名) | 一覧を開くたびに案内 | 設定「いまの状態」で見るだけ(Web 版は合っていなくても動く) |

業務の表 = システムが読む表(ID・全般設定・フィルタ・タイプ・`*_設定`・`H_*`)以外の表。

案内は一覧の上(黄色の帯)と、設定「いまの状態」の「表示する表と列の決まり」に出ます。帯の「かんたん設定」で直しに行けます。

## 2. かんたん設定の画面(設定 → かんたん設定)

```
┌ 表示する表 ────────────────────────────┐
│ [部品(3 件)        ▾] [この表を表示する] │  Level 5: 全般設定に書く(全員)
└────────────────────────────────────────┘  それ未満: この PC だけで切り替え(決まりが無い DB のとき)
┌ 編集を始める ─────────── ID が無いときだけ ┐
│ ログイン ID  tester                      │  ID の表を作って、自分を Level 5 で登録。
│ 名前 [      ]  パスワード [      ]        │  そのまま Level 5 になる。ほかの人は
│ [自分を Level 5 で登録して編集を始める]  │  あとで マスタ管理 の ID で足す
└────────────────────────────────────────┘
┌ 列ごとの決まり ──────────────── [部品] の 6 列 ┐
│ 列     入力の種類              必須 金額 並べる │
│ 品番   [自由に入力 ▾]           □    □   ◉ 大きい順 │
│ 単価   [数(打った文字を数に) ▾] ☑    ☑   ○        │
│ 仕入先 [表から 1 つ選ぶ ▾][仕入先 ▾] □  □   ○        │
│ [列の決まりを保存]                              │  <メイン>_設定 に書く(無ければ作る)
└──────────────────────────────────────────────┘
```

**入力の種類**(選ぶと `_設定`「入力形式」にこう書きます)

| 画面の呼び名 | 書くもの | 動き |
|---|---|---|
| 自由に入力 | (空) | ふつうに打つ |
| 長い文(3 行) | `/3` | 3 行の欄 |
| 数(打った文字を数にそろえる) | `数値変換` | 全角・カンマも数にする |
| 日付(カレンダーから) / 今日まで / 今日から | `calender` / `calender@過去` / `calender@未来` | カレンダーで選ぶ |
| 表から 1 つ選ぶ / いくつか選ぶ | `s<表>` / `m<表>` | 選んだ表の中身から選ぶ |
| 見るだけ(直せない) | `#VIEW#` | 表示だけ |
| 自動: 登録した人 / 登録した日時 / 直した人 / 直した日時 | `#NEWUSER#` / `#NEWDATE#` / `#UPUSER#` / `#UPDATE#` | 書くときに自動で入る |
| そのまま: … | 今までの書き方のまま | 上に無い書き方(`数値1/0/100/5`・`$フォーム/…` など)は触らない |

**必須** = `登録条件` に `必須`。**金額で見せる** = `表示` に `金額`(一覧は "#,##0"、直すときは本体の値から)。
**この列で並べる** = `ソート` に `ASC`/`DESC`(1 列だけ)。

書くのは**この 4 つの列だけ**です。参照形式・マスタ結合・履歴・追加表示・文字色設定は触らないので、
今までどおり マスタ管理 の `<メイン>_設定` で直せます(難しい決まりは今までの書き方で)。

**管理番号を足す**: 本体のいちばん右に `管理番号`(整数)を足し、いまの行に表の順で 1 から番号を振ります。
一覧で行を直す・新規・削除ができるようになります。

## 3. 列を追加(一覧・閲覧・マスタ管理)

| どこから | 足す表 | 一緒にすること |
|---|---|---|
| 一覧の「＋ 列を追加」(新規の右) | 一覧の表(本体) | `<メイン>_設定` があれば同じ名前の行を足す(同じ取引) |
| 閲覧・出力の「＋ 列を追加」 | 見ている表 | その表の `<表>_設定` があれば行を足す |
| マスタ管理の「＋ 列を追加」(0.5.0 から) | 選んだ表 | 同上 |

どれも Level 5。列名・種類(文字・整数・数値)・いまある行に入れる値 を決めて、いちばん右に足します。
足す前に本体の控えを取ります。列が決まっている表(全般設定・`_設定`・`H_` 履歴・タイプ・フィルタ)には足せません。

## 4. 番号の鍵が無い表の行(マスタ管理)

VBA のマスタ管理は 1 列目を必ず番号の鍵にしていました(新規で自動の番号・修正で変えない)。
設定の無い DB の表は 1 列目が「名前」などのことがあり、そのままでは名前を打てず、同じ名前の行を上書きしてしまいます。

0.7.0 から、1 列目が `管理番号`・`番号` か、中身がぜんぶ整数(空の表なら型が整数)のときだけ鍵にします。
そうでない表は:

- 新規 … いつも足す(同じ値の行があっても上書きしない)。1 列目も打てる
- 修正 … **見ていた行**(全列が一致するはじめの行)を直す。1 列目も変えられる。見ていた行が無ければ(ほかの端末が変えた)書かない
- 削除 … 今までどおり全列が一致する行

## 5. 試験

`tests/test_easy_setup.py`:
設定の表が 1 つも無い DB を開く → 閲覧だけでログイン → この PC で表示する表を切り替え(DB に書かない)→
「編集を始める」→ 次のログインはそのパスワード → 管理番号を足す → 列の決まり(数・必須・金額・表から選ぶ・降順)を
保存して一覧に効く → 閲覧から列を足す → マスタ管理で番号の鍵が無い表の行を足す・直す、
`_設定` の並びが違う・行が足りない・余る DB でも一覧と登録画面が開く、など。
画面は Playwright(Chromium)で、ログインから列の追加まで通して確かめた(JS のエラー無し)。
