# かんたん設定(0.8.0 / 0.9.0 / 0.12.0 〜 0.17.0)

VBA 版は、使い始めるまでに決まった表(全般設定・ID・`<メイン>_設定`)をそろえ、決まった書き方
(`calender@過去`・`s担当者`・`数値1/0/100/5` …)で打つ必要があり、**設定が面倒すぎて誰も設定できません**でした。

0.8.0 からは、決めるのは次の 2 つだけです。

| 決めること | どこで | 中身 |
|---|---|---|
| **見る DB** | 設定 →「接続先」 | どの .sqlite3 を見るか |
| **列の設定**(表ごと) | 設定 →「かんたん設定」 | 列ごとに **表示**・**入力**・**印刷**・**クリック**(0.12.0) |

全般設定・`<表>_設定`・管理番号 は**要りません**。どの表も、**一覧**で見て直せます(0.18.0 でマスタ管理・閲覧・出力の画面はなくした。同じ DB を 3 か所で見せていただけだったため)。

## 1. どの表も見て直せる

| 画面 | できること |
|---|---|
| 一覧 | 上の欄で**表を選ぶ**(業務の表がぜんぶ。この PC で覚える)。マスをダブルクリックしてその場で直す(すぐ保存)。新規・修正・参照は行の窓、削除は確かめてから。印刷・保存・コピーには「印刷」の列だけが入る |

- 行は SQLite の **rowid**(どの表にもある行の番号)で決めます。管理番号の列は要りません。
- 直すときは「画面が見ていた値」といまの値を比べ、ほかの端末が先に変えていたら書きません(「もう一度」と出る)。
- 数の型の列(INTEGER・REAL)に数を打てば、数として書きます(文字の "1500" にしない。カンマも外す)。
- 業務の表 = システムが読む表(ID・全般設定・フィルタ・タイプ・`*_設定`・`H_*`・ツールの設定)以外。

## 2. 列の設定(設定 → かんたん設定)

```
┌ 見る DB ──────────────────────────────┐
│ \\server\共有\部品台帳.sqlite3          │  替えるときは「接続先」
└───────────────────────────────────────┘
┌ 列の設定 ─────────────── [部品] の 5 列 ┐
│ 表 [部品(3 件) ▾]                        │
│ 列     表示  入力                    印刷  クリック                           │
│ 品番    ☑   [文字 ▾]                  □   [値をコピー ▾]                     │
│ 名前    ☑   [コンボボックス ▾]        ☑   [現物を開く ▾] https://社内/検索?q={値} │
│ 手順書  ☑   [文字 ▾]                  ☑   [プレビュー ▾] 手順\{値}.xlsx         │
│ 単価    ☑   [スピンボタン ▾] 刻み 0.5 ☑   [なし ▾]                           │
│ 入荷日  ☑   [カレンダー ▾]            ☑   [なし ▾]                           │
│ [列の設定を保存]                          │  編集可
└───────────────────────────────────────┘
┌ 権限(編集可 / 閲覧のみ) ─ 梱包資材マスタの「アクセス権限」┐
│ この PC     Xfa-Ngykonpo / NLM-NGY-240638               │
│ いまの権限  閲覧のみ(dbviewer:edit の行がありません)       │
│ アクセス権限マスタ [空 = DB と同じフォルダ] [保存] [読み直す] │
│ dbviewer:edit の行: 管理番号・ログインID・PC名・有効・備考  │
└──────────────────────────────────────────────┘
```

| 設定 | 意味 |
|---|---|
| **表示** | 一覧に出すか(行の窓・詳細はいつも全部の列) |
| **入力: 文字** | ふつうの欄 |
| **入力: コンボボックス** | その列に**入っている値**から選ぶ(打ってもよい)。選択肢を別に用意しなくてよい |
| **入力: スピンボタン** | 数の欄(▲▼)。**刻み** を決められる。数でなければ断る |
| **入力: カレンダー** | 日付の欄(カレンダーから選ぶ)。書く形はその列の今の形(`2026/10/15`。`2026-10-15` の列ならそれ)。無い日付は断る |
| **入力: 自動: 登録した人** | 行を足したときに、ログインした人の ID が入る(画面では直せない)。0.10.0 |
| **入力: 自動: 直した人** | 行を足した・直したときに、ログインした人の ID が入る(何も変わっていなければ入れない)。0.10.0 |
| **入力: ファイル** | ファイルの場所(`図面\A-1.pdf` のような相対パスは 設定「参照ファイルの起点」から、絶対パスも可)。マスのダブルクリック・詳細・行の窓の「プレビュー」で、**アプリの窓の中で見る**(ほかのアプリでは開かない・ダウンロードもしない)。見られるのは PDF・画像(png・jpg・gif・bmp・webp)・テキスト(txt・csv・log。Shift_JIS も可)。0.10.0 |
| **印刷** | 一覧の 印刷・保存・コピー に入れるか |
| **クリック: なし** | 今までどおり(押すと行を選ぶだけ) |
| **クリック: 値をコピー** | マスの値を **1 回押すと** コピーする(貼り付けられる)。0.12.0 |
| **クリック: 現物を開く** | マスの値を **1 回押すと** 開く。Excel・Word・PDF はその PC の**既定のアプリ**、URL は**既定のブラウザ**。0.13.0 |
| **クリック: プレビュー** | マスの値を **1 回押すと** **アプリの窓の中で**見る(中身だけ。書式・図は出さない)。0.13.0 |

### クリックで実行(0.12.0・0.13.0)

一覧・詳細・行の窓で同じです。クリックを決めた列は、マスの値に**下線**が付きます
(コピーは点線、開くは色付き)。**値の上を 1 回押す**と動きます。値の外を押せば今までどおり行を選ぶだけです。

**開くもの**(Excel・Word・PDF・URL)は、マスの値(または「場所」の決まり)から決まります。

| 開くもの | 見分け方 | 現物を開く | プレビュー |
|---|---|---|---|
| **URL** | `http://` か `https://` で始まる | 既定のブラウザ | アプリの窓の中の枠(相手のページが枠に出すのを断るときは「既定のブラウザで開く」) |
| **Excel** | `.xlsx` `.xlsm` `.xls` `.csv` | Excel | **シートのタブで 1 枚ずつ**(0.15.0)。`.xlsx` `.xlsm` は表(値。日付の書式なら日付。1 シート 2,000 行 × 100 列まで)。**`.xls` は Excel でシートごとに PDF にして見せる**(0.14.0) |
| **Word** | `.docx` `.docm` `.doc` | Word | `.docx` は見出し・段落・表(図は出さない)。**`.doc` `.docm` は Word で PDF にして見せる**(0.14.0) |
| **PDF** | `.pdf` | 既定の PDF の読み手 | そのまま |
| 画像・テキスト | `.png` `.jpg` … / `.txt` `.log` | 既定のアプリ | そのまま(テキストは Shift_JIS も可) |

**場所**(クリックで 現物を開く / プレビュー を選ぶと出る欄):

| 場所の決まり | 開く所 | 例(マスの値が `A-1`) |
|---|---|---|
| 空 | **マスの値そのもの** | 値が `手順\A-1.xlsx` ならそれ、`https://社内/図面/A-1` ならそこ |
| `{値}` を含む | `{値}` をマスの値に置き換えた所(URL なら値は符号化) | `図面\{値}.pdf` → `図面\A-1.pdf`、`https://社内/品番?no={値}` → `…?no=A-1` |
| `{値}` を含まない | 決まりの末尾に値を付けた所 | `https://社内/item/` → `https://社内/item/A-1` |

- ファイルの相対パスは 設定「**参照ファイルの起点**」から(`C:\…` や `\\server\…` の絶対パスも可)。
- 開くのは**その列に入っている値**だけです(どこのファイルでも開ける口にしない)。現物を開く のは上の形式だけ
  (`.exe` `.bat` などは開かない)。URL は http(s) だけ(`javascript:` `file:` は保存のときに断る)。
- Excel・Word のプレビューは、追加の部品なし(Python の標準だけ)で中身を読みます。書式・図・グラフは出しません。
  全部を見るときは「現物を開く」。壊れた・パスワードのかかったファイルは理由を出します。
- 開く・プレビューしたことはログに残ります(ファイルをプレビュー / ファイルを現物で開いた)。
- 一覧の右の「詳細」にも「コピー」「開く」「プレビュー」のボタンが出ます(キーボードでも押せる)。
- ダブルクリックしても 1 回しか動きません。クリックを決めた列の値を直すときは、修正(行の窓)かマスの値の外をダブルクリック。
- 「入力: ファイル」の列のプレビュー(ダブルクリック)でも、Excel・Word が見られるようになりました。
- 0.12.0 で「URL を開く」にした列は「現物を開く」として読みます。

### シートが何枚もある Excel(0.15.0)

プレビューの上に**シートのタブ**が並び、押したシートだけが出ます(← → キーでも切り替え。開き直しても同じシート)。

| | .xlsx / .xlsm | .xls(Excel で PDF) |
|---|---|---|
| 1 枚ずつ | 表をシートごとに | Excel が**シートごとに** PDF を作る(1 シート 30 ページまで・30 シートまで) |
| タブを押したとき | すぐ替わる | 作ってある PDF に替わる(**Excel をもう一度起こさない**) |
| 隠しシート | 出さない(「隠しシート N 枚は出していません」) | 同じ(Excel も印刷しない) |
| 空のシート | 「(空のシート)」 | タブに「空」。押すと理由(印刷する物がありません) |

### 古い .xls / .doc のプレビュー(0.14.0)

古い形式は Python の標準では読めず、読もうとするとエラーになりがちでした。**all-tools の点検表と同じ方式**で、
その PC の **Excel・Word に PDF にしてもらい**、PDF のまま見せます(Python に部品は足しません)。

```
Python ── cscript ──▶ office_pdf.vbs ── COM ──▶ 隠れた Excel / Word(読み取り専用で開く)
       ◀── 標準出力(PDF を base64 で) ──        ExportAsFixedFormat → 自分の TEMP に PDF → 送って消す
```

- 押すと「Excel で PDF にしています…」の窓が出て、できたら PDF に替わります(はじめは 10〜30 秒。同じファイルは 2 回目から速い)。
  長い文書・大きいブックは先頭 30 ページまで。
- PDF にできないとき(プリンターが無い・古い Office)は、Excel・Word に .xlsx / .docx にしてもらい、表・文で見せます。
- 開けないとき(パスワード付き・壊れている・Office が無い)は、**理由と止まった所**(「ブックを開く所」など)を出し、
  「現物を開く」を案内します。ログに「プレビューできなかった」で残ります。
- 標準で読めなかった .xlsx / .docx も同じ道に回します。

点検表で現場の PC を通った決まりを守っています。

| 決まり | なぜ |
|---|---|
| 読み取り専用・隠れた Excel / Word・確認を出さない・マクロとイベントを止める・リンクを更新しない | 原本を書き換えない。見えない窓で止まらない |
| 仮のパスワードを渡す | パスワード付きは**待たずに失敗**させる(見えない窓で入力を待たない) |
| Excel は IgnoreRemoteRequests | 利用者がダブルクリックした別のブックが隠れた Excel で開かない |
| PDF は VBScript の TEMP に書いて送り、すぐ消す。Python はファイルを見ない | Store 版の Python は %TEMP% を振り替えるので、受け渡すと「パスが見つかりません」になる |
| 起こした Excel・Word の **PID と作成時刻** を覚え、90 秒で終わらなければ **その PID だけ** 止める | 利用者が自分で開いている Excel・Word を巻き添えにしない |
| もともと動いていた Word が返ってきたら、隠さず・終えず・決して止めない | 利用者の Word |
| 覚えた PID は `runtime\office_processes.json` にも書き、次の起動・stop.bat で残りを止める | アプリごと止められても Excel・Word を残さない(0.11.1 と同じ考え) |
| 一度に 1 つ。同じファイル(場所・更新時刻・大きさ)は覚えておく | Excel・Word を何個も起こさない |

### 汎用に使えるか(DB を替えたら列はどうなるか)

- 設定は **DB の中の隠した表「ツールの設定」** に、**表ごと・列名ごと** に覚えます。DB を使う全員で同じです。
- **列名で**覚えるので、列の並びが変わっても**ずれません**。列が増えれば、その列は既定(表示・文字・印刷)で出ます。
- **DB を替えれば、その DB の設定**になります(その DB に設定が無ければ、どの列も既定)。前の DB の設定が別の DB に勝手に移ることはありません。
- 列の一覧は、いつも**いま開いている表の本当の列**から作ります。設定の側で列を数え直す必要はありません。

## 3. 権限(編集可 / 閲覧のみ。0.16.0)

**Level とパスワードはやめました。** Windows の**ログイン ID** と **PC 名** で、梱包資材マスタ
(`梱包資材マスタ.sqlite3`)の「**アクセス権限**」を引き、**編集可** か **閲覧のみ** かを決めます。
画面を開けば自動で入ります(ログインの画面はありません。起動モードが未設定のときだけ先にそれを決めます)。

| 権限 | できること |
|---|---|
| **編集可** | 行を足す・直す・消す、列を足す、かんたん設定の保存、表を持ってくる |
| **閲覧のみ** | 一覧で**見る・印刷・コピー・プレビュー**。直す操作は理由を出して断る(ダブルクリックは参照で開く) |

**アクセス権限の書き方**(all-tools・python-web-tools と同じ表・同じ読み方。このツールが読むのは `dbviewer:edit` だけ):

| ログインID | PC名 | 権限 | 有効 | 意味 |
|---|---|---|---|---|
| yamada | (空) | dbviewer:edit | 1 | 山田はどの PC でも 編集可 |
| (空) | NLM-NGY-240638 | dbviewer:edit | 1 | この PC は誰でも 編集可 |
| suzuki | NLM-NGY-240638 | dbviewer:edit | 1 | 鈴木がこの PC のときだけ 編集可 |

- 空欄は「問わない」。**ログインIDもPC名も空の行は誰にも効きません**(全員への許可になるため)。
- 大文字小文字・全角半角は区別しません。`有効` が 0 / false / × の行は効きません。当てはまる行の**和**を取ります。
- **当てはまる行が無ければ 閲覧のみ**(締め出さず、直す力も渡さない)。`mode:field`・`作業長` などほかのツールの権限は読みません。
- 権限は 5 分ごとに読み直します(取り消しが効く)。上の帯の「権限を確認」・かんたん設定の「読み直す」ですぐ読み直せます。
- 開発者の ID・PC(VBA の DEVELOPERFLAG)は行が無くても 編集可。

**どの梱包資材マスタか**(設定 → かんたん設定 → 権限):

- 「アクセス権限マスタ」に場所を入れて保存。**空なら、見ている DB と同じフォルダの `梱包資材マスタ.sqlite3`**。
- どちらも無ければ「決めていない」= **誰でも 編集可**(0.8.0 からの「ID の表が無い DB は誰でも直せる」と同じ)。
- 共有フォルダに届かないときは、この PC で**前回読めた結果**を使います(仕事が止まらないように)。一度も読めていなければ 閲覧のみ。
- 場所を変えられるのは 編集可 の人か、まだ決めていない・読めないとき(読めないままだと誰も直せなくなるため)。
- 権限を決めるときは読み取り専用で開きます。行を直すのは下の「アクセス権限を直す」(管理者パスワード)だけです。
- VBA 版の `ID` の表(ID・PC・PASS・Level)は使いません(表は残ります)。

**アクセス権限を直す(0.17.0。管理者パスワード)**

かんたん設定 → 権限 の下の「アクセス権限を直す」。**管理者パスワード**(既定 `nisk`。all-tools・python-web-tools と同じ)で
鍵を開けると、梱包資材マスタの「アクセス権限」の行を **足す・直す・消す** ができます(閲覧のみの人でも、パスワードを知っていれば)。

```
┌ アクセス権限を直す ───────────────────────────────┐
│ 管理者パスワード [••••] [鍵を開ける]                  │
│ → 鍵が開いています(30 分さわらなければ掛かります)[＋ 行を足す][鍵を掛ける] │
│ ☑ DBビューアの行(dbviewer:)だけ出す                  │
│ ログインID [Xfa-Ngykonpo][この PC の ID]  PC名 [NLM-NGY-240638][この PC] │
│ 権限 [dbviewer:edit ▾]  有効 ☑  備考 [  ]  [保存][やめる] │
│ 管理番号 ログインID PC名 権限 有効 備考   [直す][消す]  │
│ ▸ 管理者パスワードを変える(この PC だけ)               │
└──────────────────────────────────────────────┘
```

- 鍵は **30 分さわらなければ掛かります**(使えば延びる)。「鍵を掛ける」ですぐ掛けられます。続けて 5 回まちがえると 30 秒待ちます。
- 書く前に、梱包資材マスタの**控え**を `%LOCALAPPDATA%\DBViewer\backup` に取ります(鍵を開けてから最初の 1 回)。
- ほかの PC が先にその行を変えていたら書きません(いまの中身を出し直すので、もう一度直す)。
- ログインID と PC名 の両方が空の行は作れません(誰にも効かないため)。権限の欄は この表で使われている値から選べます。
- 「この PC の ID」「この PC」で、いま使っている ID・PC 名を入れられます。保存すると自分の権限もすぐ読み直します。
- ほかのツールの行(mode:field・作業長 …)も直せます。「DBビューアの行だけ出す」を外すと全部の行が出ます。
- **パスワードは平文で持ちません。** 変えたパスワードは PBKDF2 で撹拌してこの PC の設定に入れます(変えるには いまのパスワードが要る。
  4 文字以上。忘れたら この PC の設定の `admin_password` を消すと既定に戻る)。記録(ログ)にもパスワードは残しません。
- 足した・直した・消した・鍵を開けた(まちがえた)ことは、ログに残ります(誰が・どの PC で)。

## 4. VBA 版の DB(作業標準管理 など)も同じ(0.9.0)

`<表>_設定`(作業標準管理_設定 など)は**画面では使いません**。作業標準管理も、ほかの表と同じく
かんたん設定の 表示・入力・印刷 で動きます(一覧で直す・行の窓)。

- かんたん設定をまだ保存していない表は、`<表>_設定` の入力形式から**最初の設定**を作ります:

  | VBA 版の入力形式 | かんたん設定 |
  |---|---|
  | `calender`(`@過去`・`@未来` も) | カレンダー |
  | `数値N/最小/最大/刻み` | スピンボタン(刻みもそのまま) |
  | `s<表>` / `m<表>` | コンボボックス |
  | `#NEWUSER#` / `#UPUSER#` | 自動: 登録した人 / 自動: 直した人(0.10.0) |
  | ほか(日時の自動・`#VIEW#`・`$フォーム`・`数値変換`) | 文字 |

  作業標準管理_設定 では Ⅰ〜Ⅳ = スピンボタン、登録日・更新日・完了日 = カレンダー、登録者・更新者 = 自動: 直した人
  (VBA 版の `#UPUSER#` のまま。登録者を「足したときだけ」にするなら かんたん設定で 自動: 登録した人 に)、ほかは文字になります。
  すでに「取り込んで消す」をした DB は、かんたん設定で 登録者・更新者 の入力を選び直してください。
- 設定 → かんたん設定 の「**VBA 版の設定の表**」→「**取り込んで消す**」(Level 5)で、上の設定を「ツールの設定」に
  保存してから、`*_設定` の表をぜんぶ消します(消す前に本体の控えを取る)。
- 帳票(全般設定「帳票」)は今までどおり作れます(全般設定の「メインテーブル名」の表を一覧で見ているとき)。
  全般設定 はこの帳票のためだけに残っています(無ければ帳票のボタンが出ないだけ)。

**やめたもの**(VBA 版の `_設定` でしかできなかったこと): 日時の自動入力、必須、マスタ結合・追加表示、
金額の "#,##0" 表示、文字色、変更履歴(H_ 表への書き込み)、登録画面。
(登録者・更新者の自動入力と、参照ファイルのプレビューは 0.10.0 で かんたん設定 に足した)
H_ 表は消えずに DB に残ります(システムの表なので一覧には並べません)。

## 5. 列を追加

一覧の「新規」の右の「＋ 列を追加」(編集可)。列名・種類(文字・整数・数値)・いまある行に入れる値を決めて、いちばん右に足します。足す前に本体の控えを取ります。足した列は かんたん設定 で 表示・入力・印刷 を決めます。
